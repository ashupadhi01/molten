# About This Repository

This is an inference orchestration project using different inference engines to serve small language models, ideally under 2B parameters, locally. It is a learning project and not meant to be used as a production-grade serving engine, so suggestions should align with this fact.

The goal is to understand the primitives offered by different inference engines in depth, providing customization ability for each of them from the frontend. We will make incremental changes, avoid the trap of premature optimization, and not over-engineer things.
